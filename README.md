# Тінь Шарія

Отдельный продукт. Рабочее ТЗ находится рядом, в `../tin-shariia-tz-v2.md`.

## Техническая проба

- Локально подтверждены декодирование, измерения громкости и тишины, отказ при отсутствии аудио. Запуск: `scripts/probe-media.sh /path/to/video.mp4`. Пороги пробы предварительные.
- Синтетический ролик прошёл локальную нарезку и вертикальную сборку с сохранением AAC и заданной длительности.
- В исходниках действующего FFmpeg разрешены crop, scale, pad, trim, atrim, concat, drawtext и subtitles. Это подтверждает наличие операций в коде, но не приёмку собранного манифеста на действующем сервисе.
- API принимает входные HTTPS-адреса с разрешённых хостов. Для приватного MP4 нужно подтвердить короткоживущий адрес на точном хосте и срок действия с учётом ожидания очереди.
- В списке фильтров API отсутствуют ebur128 и silencedetect. Для отчёта нужен ограниченный профиль аудита в действующем сервисе с фиксированными параметрами и структурированным результатом.
- До пилота проверить изоляцию учётных данных и лимитов продукта, приватный вход и результаты, сценарий повтора и полный Gemini-анализ видео со звуком. Проверки на действующем FFmpeg и платный запрос Gemini пока не выполнялись.

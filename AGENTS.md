# Editorial narration

Use Soniox `tts-rt-v2`, voice `Maya`, language `uk`, speed `1.15` for all generated editorial narration, including previews, Shorts, and wide cuts. Preserve the original audio of source quotations. The server applies the speed once.

If Soniox, its quota, or a verified Maya track is unavailable, stop the narrated export and report the failure. Never substitute a system voice, another provider, a different voice, or a different speed.

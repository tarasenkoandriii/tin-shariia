# Автоматичний редакційний цикл

Основний результат — опублікований і перевірений на YouTube Short. Коментар — необов'язковий етап просування. Вимкнені коментарі не роблять джерело непридатним для випуску. Збій просування не скасовує `releaseState: published`.

## Реалізовано в цьому зміненні

`src/automation/editorial-cycle.mjs` — координатор одного етапу за виклик: discover → captions → factcheck → scenario → grok → render → audit → upload → comment → visibility. Результати попередніх етапів зберігаються. Кожен виклик отримує стабільний ключ ідемпотентності. Якщо підтвердженого розходження немає, координатор переходить до наступного джерела, не генеруючи озвучку чи відео. Типово перевіряється до 10 кандидатів.

`db-cycle-store.mjs` — PostgreSQL-сховище, міграція 0029. Створення/читання/виконання дозволені активному адміністратору; перевірки робляться на кожному виклику. Lease з окремим токеном відсікає прострочених воркерів. Після перерваного читання можливе відновлення. Перерваний платний або публікуючий етап має невідомий результат і не відправляється автоматично повторно.

`file-cycle-store.mjs` — приватний локальний журнал для тестів та однохостового воркера. Це не сховище Vercel. Відновлення простроченого файлового lock дозволене лише після зупинення його процесу; для Production слід використовувати PostgreSQL.

`project-cycle-handlers.mjs` — реальні адаптери відкриття джерела через OAuth YouTube API та черги безплатних субтитрів. Вибір прив'язаний до заданого каналу, а не до жорстко заданого ID Шарія. Закриті коментарі зберігаються як метадані просування. Збої API не трактуються як вимкнені коментарі. Немає автоматичного переходу до платного перегляду Gemini.

Координатор перевіряє прив'язку цитати до тексту і таймкодів джерела, наявність доказів, версію сценарію в оцінці Grok direct, один бал строго вище порога, відсутність фактичних ризиків, оригінальний звук цитати, незмінну Maya uk 1.15, безперервність звуку, фінальне фото і відступи штампа, допуск точного хешу медіа, публічний статус і канал завантаження, зв'язок короткого посилання з лічильником. Для завершення просування потрібне підтвердження видимості після перезавантаження і шлях до скриншота.

## Що ще не підключено

Це ядро, а не ввімкнений наскрізний автопілот. Немає production composition/dispatcher, який передає решту реальних обробників: дослідження джерел, створення/погодження сценарію, Grok, локальний або VPS-рендер, аудит, завантаження та просування. Ці служби частково існують окремо, але їх ще треба зв'язати з координатором. Немає UI запуску чи фонового розкладу нового координатора. Відсутній обробник дає `CYCLE_HANDLER_UNAVAILABLE`, а не удаваний успіх. Не вмикати публікацію за самим лише модельним прапорцем `confirmed`: адаптер фактчеку має перевірити отримані документи й використовувати чинні редакційні допуски та бюджети.

Міграцію 0029 і ці модулі ще не розгорнуто в Production. Тести з підставленими обробниками перевіряють координатор; вони не є доказом реального випуску Short.
